## Files and presentation controls

- `index.html` is the GitHub Pages entry point. `National-Housing-Bank.html` is the same self-contained downloadable presentation.
- `National-Housing-Bank.pdf` contains 18 static slides with clickable sources, a bookmark for each slide and presenter notes in PDF comment annotations. The slide pages use rendered artwork to preserve the layout. Use HTML for selectable text, accessibility and interactive activities.
- `Presenter-Notes.md` contains the speaking notes and source caveats in a convenient text format.

Open HTML directly in a browser for offline use. All images, styles and scripts are embedded. The PDF button needs the PDF in the same folder. External reference links need internet access.

Use the arrow keys, Previous / Next, or Contents to navigate. N opens the current slide’s notes. C opens Contents. F opens fullscreen where supported. Read all shows every slide with speaking notes. Timeline buttons explain milestones. The loan sliders demonstrate EMI under explicitly stated assumptions. The case rendering enlarges on click. The final knowledge check gives immediate feedback. Print exports all slides, including static explanations for interactive sections.

## Evidence and limitations

The main quantitative source is NHB’s Annual Report 2025–26. NHB’s FY runs July–June. Figures specify a period and distinguish sanctions, disbursements and outstanding balances. The loan calculator is an illustrative constant-rate model, excludes fees and subsidy, and makes no claim about an actual NHB retail offer.

NHB’s older FAQ includes obsolete ownership/regulation wording. Only its statement on the absence of direct individual loans is used. The current report and RBI material support the present mandate. The case booklet contains misaligned dates and differing material specifications. Those uncertainties are disclosed, and the 2018 launch date comes from the developer’s published results. Architectural interpretations are identified as analysis.

Developer renderings reproduced for educational discussion are credited to NHB / AFD / EU / CRISIL’s 2022 SUNREF booklet, pp.49 and 56. They are not photographs or measured as-built drawings. Image rights remain with the respective owners. This is a student presentation, not an official NHB website.
